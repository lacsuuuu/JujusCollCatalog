# Juju's Coll Catalog
Juju's Coll Catalog is sa Web App that catalogs existing merchandise from various kpop groups.  
  
The Catalog lets the user:
- Build a custom profile where their collection and wishlists are shown
- Build a catalog of various merchandise from different kpop groups
- Build a digital binder that can be used to visualize their Binder in real life.
- Post Images and be showcased as a Feed.
- Add a group, its members, and their era/comebacks.
- Build a custom profile for the Groups and Members.

# Note:
This project is mainly for self consumption and as of right now not planned to be published or to be used by the public.
This Project is AI assisted.

# The Project Uses:
- React (for front-end)
- Firebase (for the general text-based database elements)
- Cloudinary (for the storage of uploaded images.
